# Project setup

This is a static p5.js sketch. It has no package-install step or backend.

## Run on Replit

Start the **Serve static** workflow and open Preview. The workflow serves the project root, with `index.html` as the entry page. Changes to HTML, CSS, JavaScript, and images are picked up automatically; refresh Preview to see them.

The sketch loads p5.js 1.6.0 from jsDelivr, so the browser needs internet access when the page loads.
